当您访问本网站时

  • 不使用任何 Cookie，不使用任何追踪器，也不使用任何访问量统计或广告工具。
  • 网页不调用任何第三方服务：字体和图片均由本网站自身提供。
  • 收银演示在您的浏览器中运行。您在演示中的任何操作都不会被传输或保存。

与所有托管服务商一样，GitHub, Inc.（GitHub Pages）会接收显示网页所需的技术数据，尤其是您的 IP 地址，并对其进行处理，以保障服务的安全和正常运行。由于 GitHub 位于美国，这些数据可能在美国处理。该处理的条件以及数据跨境传输所适用的保障措施，详见 GitHub 隐私声明。OXYGENE NUMERIQUE 无法访问这些日志。

当您与我们联系时

如果您通过电子邮件或电话与我们联系，我们会使用您提供的信息（姓名、联系方式、店铺、留言内容）回复您、准备报价单，并跟进您的商务咨询。

  • 法律依据：应您的要求采取的合同前措施，其后为我们跟进商务关系的正当利益。
  • 接收方：仅限 OXYGENE NUMERIQUE 负责处理您请求的人员，以及作为技术服务商的电子邮件服务提供商。您的数据不会被出售或出租。
  • 保存期限：如未签订合同，自最后一次沟通起保存三年。如您成为客户，则在合同期内保存，此后依照适用的会计和税务保存期限保存。

当您使用 Joli Comptoir 软件时

本软件安装在店铺的电脑上。销售日志、日结、归档、库存和设置均保存在本地。OXYGENE NUMERIQUE 无法访问这些数据，也不会接收任何销售数据。

  • 本软件不记录店铺顾客的姓名、联系方式或银行数据。银行卡支付由店铺的刷卡机处理，该设备独立于本软件。
  • 用于为日志签名的密钥存放在电脑操作系统的安全钥匙串中。
  • 从 Shopify 导入商品目录时，仅读取店铺商品的公开信息（名称、价格、图片）。

店铺对其使用本软件处理的数据承担责任。如店铺请求的技术支持需要访问其电脑或数据，OXYGENE NUMERIQUE 将作为数据处理者，依照店铺的指示、仅在支持服务期间进行操作，符合《通用数据保护条例》（GDPR）第28条及通用条款的规定。
